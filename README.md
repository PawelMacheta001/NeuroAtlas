# NeuroAtlas v3 — visual cannabis edition

Najważniejsze poprawki względem v2:
- widoczne ilustracje jako prawdziwe elementy `<img>`, nie tylko tła,
- każda strona tematu i kursu ma okładkę + dodatkowe wizualizacje w treści,
- sticky progress na stronach kursów,
- mocniej zróżnicowana typografia i sekcje,
- dłuższe treści wyciągnięte i rozwinięte z istniejącej bazy danych.

## Pliki
- `index.html`
- `styles.css`
- `app.js`
- `data/data.js`

## Technicznie
Ilustracje są generowane jako SVG data URI w przeglądarce. Dzięki temu:
- każdy temat ma własną ilustrację,
- nie trzeba przechowywać setek osobnych obrazów,
- projekt pozostaje lekki.


## v4
- bardziej zróżnicowane ilustracje tematów,
- główna okładka z motywami cannabis (medyczna + rekreacyjna),
- ilustracje tematów są bardziej semantyczne i łatwiejsze do zapamiętania.


## v5
- uproszczone miniatury w listach tematów i krokach kursów,
- oddzielne ilustracje dla każdego kursu,
- kursy nie różnią się już tylko kolorami.


## V6
- Tematy: duży, prosty symbol zamiast schematu/mapy.
- Kursy: 6 całkowicie różnych kompozycji okładek.
- Widoczny badge V6 w logo, żeby łatwo rozpoznać właściwy plik.
- Tło strony: subtelne motywy rekreacyjne i medyczne cannabis.
